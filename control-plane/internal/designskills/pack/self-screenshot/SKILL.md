# Live-preview review belongs to Hannibal

Hannibal, the chat agent, captures and inspects the preview. The coding agent
implements the requested experience and runs functional checks. The platform
screenshot bridge does not return preview captures to the coding agent.

Send a concise bridge report at meaningful milestones: which screen is usable,
what changed, which checks passed and anything still unverified. Continue the
remaining implementation; do not wait or poll for a review. Apply the specific
visual corrections Hannibal sends through the existing task conversation.

Do not capture the live preview yourself, install screenshot tools, or change
routes, authentication or passcode gates for a capture. User-supplied design
references remain valid inputs. If a protected screen cannot be inspected
through available authorized tools, report the limitation. Never claim visual
verification from compilation or an unseen screenshot.
